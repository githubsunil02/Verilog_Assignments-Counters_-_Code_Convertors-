## ### # 📑 ASCII Quick Reference

### 🗺️ Core Ranges
* **Digits ('0'-'9'):** `0x30` - `0x39` (Dec: 48-57)
* **Uppercase ('A'-'Z'):** `0x41` - `0x5A` (Dec: 65-90)
* **Lowercase ('a'-'z'):** `0x61` - `0x7A` (Dec: 97-122)

### 📊 Anchor Values
* **'0'** = `0x30` (48)
* **'A'** = `0x41` (65)
* **'a'** = `0x61` (97)
